# Healthcare-Insurance-Claim-Analysis
### 📊 Project Overview  
This project focuses on **analyzing healthcare claims data** to extract key insights related to patients, claims, and medical expenses. Using **Tableau** for interactive visualizations and **Excel/Python** for data preprocessing, the goal is to uncover patterns that can help optimize costs, improve claim management, and support data-driven decisions in healthcare organizations.

---

### 🧠 Objectives  
- Analyze healthcare claim data to identify trends in **patient demographics, claim types, and cost distribution**.  
- Build an **interactive Tableau dashboard** to visualize medical claims and performance metrics.  
- Provide insights that can help improve **efficiency and decision-making** in healthcare operations.  

---

### 🗂️ Dataset  
**File:** `ABC Healthcare Company Claims Dataset.xlsx`  
- Contains anonymized data related to patient claims.  
- Includes columns like `Patient ID`, `Age`, `Gender`, `Diagnosis`, `Claim Amount`, `Provider`, `Region`, and `Claim Status`.
